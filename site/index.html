Hold Alt to take over. 按住 Alt 自己试试。

Driven by an actual recorded match, replayed at real speed and looping. The background is a placeholder colour, not real gameplay. 由一份真实对局录制驱动，按原速循环播放。 背景是占位色，不是真实游戏画面。

No installer — a single exe. MIT licensed. 没有安装程序，就一个 exe。MIT 许可。

What it remembers for you它替你记的那些事

Five timers五个倒计时

Mid rune, bounty, lotus, wisdom rune and the stacking window. A nearly-empty ring means it's nearly up.

中路符、赏金、莲花、智慧神符、堆野窗口。 环快走完就是快刷了，不用读数字。

Glyph and buyback敌方塔防与买活

Glyph implements the full refresh rules (first T1/T2/T3/melee barracks lost). Buyback is announced once and then gone — here it stays as state.

塔防实现了完整的刷新规则（丢首座 T1/T2/T3/近战兵营各刷新一次）。 买活游戏只播报一次、过后查不到，这里把它保留成状态。

Ward map眼位地图

Colour is ownership, shape is state. Your wards get a countdown; enemy wards are remembered and fade as the information gets older.

颜色说归属，形状说状态。我方眼带到期倒计时； 敌方眼会被记住，并随着线索变旧而逐渐淡化。

Why this is safe为什么这是安全的

Does not它不做 read game memory · modify game files · inject into the process · hook graphics APIs · simulate input · touch the network at runtime 读游戏内存 · 修改游戏文件 · 注入进程 · hook 图形 API · 模拟任何输入 · 运行时联网
Does它只做 accept the JSON that Dota 2 itself POSTs to 127.0.0.1 through GSI, Valve's official interface — the same mechanism Logitech and Razer drivers use 接收 Dota 2 自己通过 GSI POST 到 127.0.0.1 的 JSON——Valve 官方的接口， 罗技、雷蛇的驱动用的是同一套机制

During a match GSI only pushes your own data, so by design it cannot reveal hidden information. Anything here you could see yourself by pressing Tab — it just remembers the timing. The source is open; go read it. GSI 在对局中只推送玩家本人的数据，设计上就无法用于获取隐藏信息。 这里能算出来的，你自己按 Tab 一样能看到，只是它替你记住了时间。源码全部公开，可以自己核。

Requirements运行条件

OS系统 Windows 10 / 11
Display显示模式 Borderless window. Exclusive fullscreen cannot show any non-injecting overlay — that's an OS limitation. 无边框窗口。独占全屏下任何非注入类悬浮层都无法显示， 这是系统级限制。
Setup设置 Add -gamestateintegration to Dota 2's launch options. The app writes the GSI config file itself on first run. 给 Dota 2 的启动项加上 -gamestateintegration。 首次运行时程序会自动写入 GSI 配置文件。
