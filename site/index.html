This is the real overlay, running the same code as the download. Hold Alt to take over.

Driven by an actual recorded match, replayed at real speed and looping. The background is a placeholder colour, not real gameplay.

Download for Windows View on GitHub

No installer — a single exe. MIT licensed.

What it remembers for you

Five timers

Mid rune, bounty, lotus, wisdom rune and the stacking window. A nearly-empty ring means it's nearly up.

Glyph and buyback

Glyph implements the full refresh rules (first T1/T2/T3/melee barracks lost). Buyback is announced once and then gone — here it stays as state.

Ward map

Colour is ownership, shape is state. Your wards get a countdown; enemy wards are remembered and fade as the information gets older.

Why this is safe

Does notread game memory · modify game files · inject into the process · hook graphics APIs · simulate input · touch the network at runtime
Doesaccept the JSON that Dota 2 itself POSTs to 127.0.0.1 through GSI, Valve's official interface — the same mechanism Logitech and Razer drivers use

During a match GSI only pushes your own data, so by design it cannot reveal hidden information. Anything here you could see yourself by pressing Tab — it just remembers the timing. The source is open; go read it.
