### 多语言 —— 界面已完成（2026-09-08），只剩文档

**界面部分（编辑态卡片 + 托盘菜单）已经做完**，设计结论见
[design/overlay.md](design/overlay.md) 的"多语言"一节。下面保留的是当初的决策记录
和**仍未完成的文档双语**。

**范围：只做简体中文和英文。**

**不上 i18n 框架**，理由（免得以后重新讨论）：

1. 框架值钱的地方是复数规则、ICU 消息格式、locale 懒加载、词条抽取工具链、
   fallback 链。我们是 20 条静态短语 × 2 种语言，一条插值都没有，这些能力全用不上。
2. **前端现在没有构建步骤**——`ui/` 是原生 ES 模块，编译期直接嵌进二进制。
   引框架要么加打包器、要么往仓库里塞 UMD；而覆盖层必须离线可用，CDN 这条路本来就堵死。
3. **托盘菜单在 Rust 侧**，JS 框架管不到。无论如何都得有一份两边都能读的东西，
   那正好就是一个 JSON——框架在这里只覆盖一半，还多一套机制。

需要的就是 `T[lang][key]` 加一条"缺键回退中文"，十几行。

**语言包走"常数外置"那套**：`constants/lang.zh-CN.json` / `lang.en.json` 播种到配置目录。
Rust 和前端都已经会读那个目录，白捡一致性；翻译别扭时改 JSON 重启即可，不必重新编译。

**会改主意的情形**：词条涨到几百条、有第三方帮忙翻译（那时抽取和校验工具才值钱）、
或需要复数/日期本地化。目前数字已用 `toLocaleString` 处理，日期没用到。

框架唯一能白给而我们会缺的是**漏翻检查**——用一段 grep 比较两份 JSON 的键集合即可补上。

> **原先最难的那一条在动工前就消失了。** 之前记的是：面板宽度写死（`.cell` 60px、
> 买活 104px、净资产 116px），而"净资产"换成 `Net Worth` 会更宽，直接翻译会撑破或截断，
> "得让宽度跟着语言走"。图标化之后面板上没有词，这个约束不复存在——
> 这才是图标化真正的收益，不是省掉那十几条翻译。

## 功能

### 每块单独调大小 —— 等具体需求（2026-09-08 讨论）

现在是全局一套缩放，外加眼位地图自己的尺寸滑块。问过要不要给每块都配一个，**先不加**。

理由不是"嫌麻烦"，是**眼位那个滑块并不是"每块的缩放"**：地图内容是固定的 ±8400 世界
塞进 N 像素，调大是**看到更多细节**；其余三块的内容是图标和数字，可读性由全局缩放
统一管——两者性质不同。真给每块加缩放，眼位那块就会有两套重叠的机制
（全局缩放 × wardSize），调起来反而绕。

**触发条件**：出现一个具体的需求，比如"倒计时想再大点但净资产想小点"。
真到那时，最省的形态也不是四个独立滑块，而是在全局缩放之上给每块一个倍率。

### 触发键可配

现在写死 Alt（`GetAsyncKeyState(VK_MENU)`）与 `Ctrl+Alt+F10`（编辑态）。
当初明确说"这一版先不做"。

### 常显模式

设计里留过这条兜底——万一 `GetAsyncKeyState` 在某些环境不工作，
至少还能常显。目前只有开发页的 `v` 键，正式版没有这个开关。

### 价格表未加载时的提示

设计里写过"首次运行且无网则净资产项显示『价格表未加载』"，实际没做——
现在会静默退到内嵌快照。快照会随版本变旧，用户看到的是**看起来正常但偏低**的数字，
比明说更糟。

### 敌方英雄失踪计时

数据可行（`minimap_enemyicon` 带英雄名 + 坐标），但实测每个敌人每局消失 11~19 次、
中位仅 5~19 秒，直接做成提醒会非常吵。

**卡在设计而不是实现上**：得先想清楚"多久才算失踪"，以及怎么表达才不打扰。

目前只有"开/关"这一个最小实现。缺：

- 自动清理（现在只增不减，一局约 4MB，得手动删）
