## 功能

### 每块单独调大小 —— 等具体需求（2026-09-08 讨论）

现在是全局一套缩放，外加眼位地图自己的尺寸滑块。问过要不要给每块都配一个，**先不加**。

理由不是"嫌麻烦"，是**眼位那个滑块并不是"每块的缩放"**：地图内容是固定的 ±8400 世界
塞进 N 像素，调大是**看到更多细节**；其余三块的内容是图标和数字，可读性由全局缩放
统一管——两者性质不同。真给每块加缩放，眼位那块就会有两套重叠的机制
（全局缩放 × wardSize），调起来反而绕。

**触发条件**：出现一个具体的需求，比如"倒计时想再大点但净资产想小点"。
真到那时，最省的形态也不是四个独立滑块，而是在全局缩放之上给每块一个倍率。

### 触发键可配

现在写死 Alt（`GetAsyncKeyState(VK_MENU)`）与 `Ctrl+Alt+F10`（编辑态）。
当初明确说"这一版先不做"。

### 常显模式

设计里留过这条兜底——万一 `GetAsyncKeyState` 在某些环境不工作，
至少还能常显。目前只有开发页的 `v` 键，正式版没有这个开关。

### 价格表旧了要能提示 —— 只做了一半（2026-09-16）

原设计是"首次运行且无网则净资产项显示『价格表未加载』"。运行时不联网之后前半句
不成立了，但**后半句的病还在**：快照会随 Dota 版本变旧，用户看到的是
**看起来正常但偏低**的数字，比明说更糟。

**便宜的那一半已经做了**：设置卡片的开发区显示程序版本和价格表对齐的 Dota 版本，
用户报"数字不对"时能直接念出来，不必翻日志。见
[design/overlay.md](design/overlay.md) 的「设置」第 8 条。

**真正的解法仍然没做**：要主动提示"表旧了"，程序得在运行时知道**当前**装的是哪个
Dota 版本，而那要读游戏安装目录——与"发布出去的程序不碰安装目录"冲突。
于是现在只能是用户先察觉不对、再来对版本号，程序自己发现不了。

### 文档与项目主页（2026-09-14 提出）

两件事，做的时候一起做：**把 README 做厚**，以及**开一个 GitHub Pages 站**。

参考 [flyxl/datazen](https://github.com/flyxl/datazen) 的 README。它值得学的地方：

- **开头是「为什么有这个东西」，不是「这是什么」**。我们现在的 README 也是这个路子，
  可以再往前推一步
- **「三分钟上手」单独成节**，把最小可用路径和后面的细节彻底分开
- **功能按真实使用场景分小节展开**，每节配一张截图。它有 8 张以上，
  而我们只有一张覆盖层实拍——这是差距最大的地方
- 表格用来放"支持矩阵"这类对照信息；ASCII 图用来画模块关系
- 末尾有「安全与隐私」独立一节。我们有「为什么这是安全的」，位置可以更靠后、写得更细
- 双语。**注意方向相反**：datazen 是英文主体 + 中文译本，而我们的约定是
  [中文是源头、英文是译文](design/overlay.md)，不要跟着它改

**截图是这件事的主要成本。** 现在只有一张，且背景是回放工具的占位色。
要补的至少有：四个块各自的特写、编辑态卡片、眼位地图上有敌方眼的样子。
编辑态那张历史上没截成功过（卡片比可用窗口高，`PrintWindow` 只渲染屏上部分），
需要另想办法。

#### GitHub Pages：可以让页面上跑真程序

2026-09-14 查过可行性，结论是**这个项目恰好很适合做 live demo**，而不是放几张截图：

- 前端本来就是无框架的 vanilla JS + SVG，本来就能在浏览器里跑（`ui/dev.html` 就是）
- [`source.js`](../ui/js/source.js) 的 `connectSource()` 只有一个接缝
  （Tauri 事件 / SSE），加第三个分支「从静态文件回放」是很小的改动
- 其余全是 `fetch("/constants/*.json")`，静态站原样能用
- 仓库公开，Pages 免费，CI 已经有了

所以首屏可以是**真实录制驱动的真实覆盖层在循环播放**——同一份 `ui/js`，
不是截图也不是录屏，访客还能按住 Alt 亲手试那个唯一的交互。

**三个必须先解决的点（查证过，不是猜的）：**

1. **录制里有身份信息。** 实测一包里有 `player.steamid`、`accountid`、
   `player.name`（Dota 昵称）、`map.matchid`。直接发到公网等于公开这些，
   做 demo 前必须洗一遍，顺带只留 demo 用得上的字段，体积也跟着降
2. **`fetch("/constants/...")` 是绝对路径。** 部署在
   `https://<user>.github.io/dota2-game-helper2/` 这种子路径下会 404。
   要给浏览器分支一个可配的 base 前缀（Tauri 分支走 `invoke`，不受影响）。
   **这是唯一一个一定会咬人的地方**
3. **得剪一段合适的 dump。** 完整录制 18~47MB，太大也太长。剪两三分钟、
   包含一次插眼、一次买活、一次符刷新，让四个块都有东西可看

站点内容建议就两页：**首页**（自动播放的 demo + 下载按钮指向 Releases）+
**使用文档**（下面那条正欠着）。`docs/design/*` 是中文开发笔记，不该当用户文档发出去。

> 明确不做的：**浏览器版覆盖层**（网页直接收 GSI）。技术上要在本机再跑一个服务
> 把 GSI 转给页面，等于把一个 exe 换成「服务 + 浏览器」；而覆盖层的全部价值在于
> **压在游戏画面上**，浏览器窗口做不到。

### 安装包（nsis）—— tag 和 Release 早就有了，缺的只是安装包

原文写的是"没打过 tag、没出过安装包"，**前半句从 v1.0.0 起就不成立了**：
现在有 v1.0.0 / v1.1.0 / v1.2.0 / v1.2.1 / v1.2.2 五个 tag 和对应的 GitHub Release，
每次都附一个 zip（exe + 两份 README），发布后会把 zip 下载回来核对 SHA256。

**还缺的是 nsis 安装包。** `bundle.targets` 配着它，但 `tauri build` 的打包流程从没跑过。
真要做的话至少要确认：能装、能卸、首次运行会正确写 GSI cfg 与播种常数表。

不急的理由：zip 解压即用，而这个程序本来就没有需要写进注册表或开始菜单的东西。
安装包真正的收益是"卸载时清干净"——而它写出去的只有
`%APPDATA%\dev.dota2helper2.app` 和一个 GSI cfg，README 里已经写明怎么手动删。

## 已明确不做

记在这里免得反复讨论。理由见各自的设计文档。

| | 原因 |
|---|---|
| 开机自启 | 用不着 |
| 语音提示 | 前作的方案，吵 |
| 白天黑夜倒计时 | 游戏原生已显示 |
| 肉山 / 不朽盾计时 | 同上，游戏原生已显示（2026-09-08 定）。数据其实是够的——顶层 `roshan` 段玩家视角确实没有，但 `roshan_killed`（带 `killed_by_team`）和 `aegis_picked_up` 两个事件都会推过来，足以算重生窗口和盾过期。不做是因为原生已有，不是因为做不了。 |
| 任何输入模拟 | 违背"纯接收器"定位 |
| 敌方塔血量 | `buildings` 段只有己方，无数据 |
| 观察者哨塔归属 | `team` 恒为 5（中立），GSI 不体现占领状态 |
| 队友 / 敌人的个体数据 | GSI 玩家视角不提供 |
| 掉在地上的装备计入净资产 | GSI 只推自己物品栏，无解 |
| 格子内部再做视觉层级 | **按现状保留（2026-09-20 定）。** 面板拆四块解决了"块摆在哪"；格子内部 `far/near/now` 三档只有透明度 .78→1 和环粗 4→6，九项基本等权重。曾记为"等实战看清楚哪些格子是一眼要看到的再说"，实战下来的判断是**现在这样就够用**。真要动，先得拿出"按住 Alt 那半秒找错了目标"的具体例子，否则放大/压暗只是换一种拍脑袋。 |
| 敌方英雄失踪计时 | **2026-09-21 定。** 数据本来可行（`minimap_enemyicon` 带英雄名和坐标），但**游戏原生的小地图已经把这件事显示了**——敌方英雄在哪、还在不在视野里，抬头就能看见。我们再算一遍"消失了多久"是在重复它已经给的信息，而这个覆盖层的定位是"对局中游戏**不告诉你**的事"。<br><br>实现上也不占便宜：实测每个敌人每局消失 11~19 次、中位仅 5~19 秒，做成提醒会非常吵，得先解决"多久才算失踪"和"怎么表达不打扰"——**为一件原生已有的事付这个设计成本不划算**。 |
| 观战 / 看回放时工作 | 定位就是"你正在打的那一局"（2026-09-08 定）。观战和回放已经有一堆现成工具，而这个覆盖层要解决的是对局中游戏不告诉你的事。技术上能做半套（符与眼位只依赖 `map` / `minimap`，观战下反而更全；坏的只有净资产和敌方买活），但半开的面板会让人以为是坏了。改成**检测到就整窗隐藏**，判定方式见 [design/overlay.md](design/overlay.md) 的"智能显隐"。 |
