### 多语言 —— 界面已完成（2026-09-08），只剩文档

**界面部分（编辑态卡片 + 托盘菜单）已经做完**，设计结论见
[design/overlay.md](design/overlay.md) 的"多语言"一节。下面保留的是当初的决策记录
和**仍未完成的文档双语**。

**范围：只做简体中文和英文。**

**不上 i18n 框架**，理由（免得以后重新讨论）：

1. 框架值钱的地方是复数规则、ICU 消息格式、locale 懒加载、词条抽取工具链、
   fallback 链。我们是 20 条静态短语 × 2 种语言，一条插值都没有，这些能力全用不上。
2. **前端现在没有构建步骤**——`ui/` 是原生 ES 模块，编译期直接嵌进二进制。
   引框架要么加打包器、要么往仓库里塞 UMD；而覆盖层必须离线可用，CDN 这条路本来就堵死。
3. **托盘菜单在 Rust 侧**，JS 框架管不到。无论如何都得有一份两边都能读的东西，
   那正好就是一个 JSON——框架在这里只覆盖一半，还多一套机制。

需要的就是 `T[lang][key]` 加一条"缺键回退中文"，十几行。

**语言包走"常数外置"那套**：`constants/lang.zh-CN.json` / `lang.en.json` 播种到配置目录。
Rust 和前端都已经会读那个目录，白捡一致性；翻译别扭时改 JSON 重启即可，不必重新编译。

**会改主意的情形**：词条涨到几百条、有第三方帮忙翻译（那时抽取和校验工具才值钱）、
或需要复数/日期本地化。目前数字已用 `toLocaleString` 处理，日期没用到。

框架唯一能白给而我们会缺的是**漏翻检查**——用一段 grep 比较两份 JSON 的键集合即可补上。

> **原先最难的那一条在动工前就消失了。** 之前记的是：面板宽度写死（`.cell` 60px、
> 买活 104px、净资产 116px），而"净资产"换成 `Net Worth` 会更宽，直接翻译会撑破或截断，
> "得让宽度跟着语言走"。图标化之后面板上没有词，这个约束不复存在——
> 这才是图标化真正的收益，不是省掉那十几条翻译。

## 功能

### 每块单独调大小 —— 等具体需求（2026-09-08 讨论）

现在是全局一套缩放，外加眼位地图自己的尺寸滑块。问过要不要给每块都配一个，**先不加**。

理由不是"嫌麻烦"，是**眼位那个滑块并不是"每块的缩放"**：地图内容是固定的 ±8400 世界
塞进 N 像素，调大是**看到更多细节**；其余三块的内容是图标和数字，可读性由全局缩放
统一管——两者性质不同。真给每块加缩放，眼位那块就会有两套重叠的机制
（全局缩放 × wardSize），调起来反而绕。

**触发条件**：出现一个具体的需求，比如"倒计时想再大点但净资产想小点"。
真到那时，最省的形态也不是四个独立滑块，而是在全局缩放之上给每块一个倍率。

### 触发键可配

现在写死 Alt（`GetAsyncKeyState(VK_MENU)`）与 `Ctrl+Alt+F10`（编辑态）。
当初明确说"这一版先不做"。

### 常显模式

设计里留过这条兜底——万一 `GetAsyncKeyState` 在某些环境不工作，
至少还能常显。目前只有开发页的 `v` 键，正式版没有这个开关。

### 价格表旧了要能提示 —— 只做了一半（2026-09-16）

原设计是"首次运行且无网则净资产项显示『价格表未加载』"。运行时不联网之后前半句
不成立了，但**后半句的病还在**：快照会随 Dota 版本变旧，用户看到的是
**看起来正常但偏低**的数字，比明说更糟。

**便宜的那一半已经做了**：设置卡片的开发区显示程序版本和价格表对齐的 Dota 版本，
用户报"数字不对"时能直接念出来，不必翻日志。见
[design/overlay.md](design/overlay.md) 的「设置」第 8 条。

**真正的解法仍然没做**：要主动提示"表旧了"，程序得在运行时知道**当前**装的是哪个
Dota 版本，而那要读游戏安装目录——与"发布出去的程序不碰安装目录"冲突。
于是现在只能是用户先察觉不对、再来对版本号，程序自己发现不了。

### 敌方英雄失踪计时

数据可行（`minimap_enemyicon` 带英雄名 + 坐标），但实测每个敌人每局消失 11~19 次、
中位仅 5~19 秒，直接做成提醒会非常吵。

**卡在设计而不是实现上**：得先想清楚"多久才算失踪"，以及怎么表达才不打扰。

## 开发向

### 录制的后续处理 —— 清理已做，分文件还没（2026-09-16）

**手动清理已经做了**：开发区显示录制文件的个数与总体积，配一个「清空录制」按钮。
刻意不做自动清理，理由见 [design/overlay.md](design/overlay.md) 的「设置」第 8 条——
一句话是：自动删掉的很可能正是待验清单在等的那一局，而打过的对局回不来。

剩下的两件：

- **按对局分文件**（现在是按开关时机分，一个文件可能横跨多局或只有半局）。
  注意这条**不再是清理的前提**了：当初说"得先分文件"是在往自动清理上推——
  只有让程序替你决定留哪个，它才需要知道哪个文件是哪一局。手动清理里做决定的是人。
  它现在的价值只剩"回放时不用自己找那一局从哪开始"。
- **导出 / 挑选片段**。做 GitHub Pages 的 live demo 要剪一段两三分钟的 dump，
  那时这条会变成必需，见下面「文档与项目主页」。

### 用排眼事件消掉剩下的幽灵眼（2026-09-15 提出）

敌方眼加了 `firstSeen` 物理上界之后，三局里两局的幽灵清零，但第三局还剩 4 段。
查清了：**全是插下没多久就被排掉的眼**（真实存活 34/35/60/106 秒，而寿命是 360/420），
它们在我方真视之外被杀，我们无从得知，只能挂到名义寿命。
`firstSeen` 剪的是"活过头"的，对"死太早"的帮不上忙。

**有个现成信号一直没用**：`CHAT_MESSAGE_OBSERVER_WARD_KILLED` /
`CHAT_MESSAGE_SENTRY_WARD_KILLED`。观战录制里一局 39 条，而且更早的自己打的录制里
也见过这两个类型，说明自己打时也收得到（只会收到自己队伍的排眼消息——
而这恰好就是要覆盖的情况：**我方排掉了敌方的眼**）。

**缺陷是事件里没有坐标**，只有 `playerid1`（谁排的）和一个 `value`。所以知道
"有一个敌方假眼被排了"，不知道是哪一个。可行的做法：

- 只记着一个该类型的敌方眼时 → 直接删掉，无歧义
- 记着多个时 → 按排眼者位置就近删

**动手前要先验三件事**（都需要一份自己打的录制，观战那三份验不了）：

1. 自己打时这两个事件确实收得到，且只包含本方排眼
2. 同一时刻通常记着几个敌方眼——如果多数时候只有一两个，"无歧义直接删"就够用了
3. 能不能从 `minimap` 的英雄图标定位到 `playerid1` 那个队友

  而我们只有一张覆盖层实拍——这是差距最大的地方

- 双语。**注意方向相反**：datazen 是英文主体 + 中文译本，而我们的约定是
  [中文是源头、英文是译文](design/overlay.md)，不要跟着它改

**截图是这件事的主要成本。** 现在只有一张，且背景是回放工具的占位色。

#### GitHub Pages：可以让页面上跑真程序

2026-09-14 查过可行性，结论是**这个项目恰好很适合做 live demo**，而不是放几张截图：

- 前端本来就是无框架的 vanilla JS + SVG，本来就能在浏览器里跑（`ui/dev.html` 就是）
- [`source.js`](../ui/js/source.js) 的 `connectSource()` 只有一个接缝
  （Tauri 事件 / SSE），加第三个分支「从静态文件回放」是很小的改动
- 其余全是 `fetch("/constants/*.json")`，静态站原样能用
- 仓库公开，Pages 免费，CI 已经有了

所以首屏可以是**真实录制驱动的真实覆盖层在循环播放**——同一份 `ui/js`，
不是截图也不是录屏，访客还能按住 Alt 亲手试那个唯一的交互。

**三个必须先解决的点（查证过，不是猜的）：**

1. **录制里有身份信息。** 实测一包里有 `player.steamid`、`accountid`、
   `player.name`（Dota 昵称）、`map.matchid`。直接发到公网等于公开这些，
   做 demo 前必须洗一遍，顺带只留 demo 用得上的字段，体积也跟着降
2. **`fetch("/constants/...")` 是绝对路径。** 部署在
   `https://<user>.github.io/dota2-game-helper2/` 这种子路径下会 404。
   要给浏览器分支一个可配的 base 前缀（Tauri 分支走 `invoke`，不受影响）。
   **这是唯一一个一定会咬人的地方**
3. **得剪一段合适的 dump。** 完整录制 18~47MB，太大也太长。剪两三分钟、
   包含一次插眼、一次买活、一次符刷新，让四个块都有东西可看

站点内容建议就两页：**首页**（自动播放的 demo + 下载按钮指向 Releases）+
**使用文档**（下面那条正欠着）。`docs/design/*` 是中文开发笔记，不该当用户文档发出去。

> 明确不做的：**浏览器版覆盖层**（网页直接收 GSI）。技术上要在本机再跑一个服务
> 把 GSI 转给页面，等于把一个 exe 换成「服务 + 浏览器」；而覆盖层的全部价值在于
> **压在游戏画面上**，浏览器窗口做不到。
