## 等实战验证结束再动

清单里的项目验完之前，显示层的事都先压着——现在改布局，验出来的结论可能就白费了。

### 面板布局

九项全开时面板是横向一长条，1920 宽下占掉近半屏；缩放 1.5×（当前实际在用的值）更挤。

可能的方向：分组换行、分区、或者按紧急度动态取舍。**先别定方案**，
等实战里看清楚"哪些是真的一直在看、哪些只是偶尔瞄一眼"再说。

### 自有图标

现在用的是金色圆环，取自面板的环形倒计时，16px 下可读，但看不出和 Dota 有关。

前作用的是 Valve 的压制之刃素材，**本仓库公开，不宜沿用**。
方向上讨论过三条：环形母题再推一步 / 原创的 Dota 相关符号 / 字母标。没定。

约束：托盘实际显示是 16×16，细线条和高饱和色块在那个尺寸下都不行。

### 多语言

**要翻的文案很少，难的是布局。**

用户可见的中文一共约 20 条：

| 位置 | 内容 |
|---|---|
| `ui/js/timers.js` `KIND_LABEL` | 符类型标签（赏金/圣水/强化/智慧/莲花/堆野） |
| `ui/js/render.js` | 敌买活、净资产 |
| `ui/js/settings.js` `SHOW_ITEMS` | 9 个显示项名 |
| `ui/js/editor.js` | 卡片分区标题、滑块标签、完成按钮、提示条、打开常数表目录 |
| `src-tauri/src/tray.rs` | 编辑面板、退出 |

`wardmap.js` / `minimap.js` / `networth.js` / `cachepool.js` 里的中文**全是注释**，不用动。
Rust 侧除 `tray.rs` 外的中文**全是日志**，给开发者看的，不该翻译。

真正的工作量在这两处：

1. **面板宽度是写死的**（`.cell` 60px、买活 104px、净资产 116px）。
   写死是为了防抖动——净资产从 4 位涨到 5 位时若自适应，居中面板会整体横移。
   但"净资产"三个字换成 `Net Worth` 会更宽，直接翻译会撑破或截断。
   得让宽度跟着语言走（每语言一套宽度变量），或者给英文选更短的措辞。
2. **托盘菜单在 Rust 侧、面板在前端**，两边各需一份词条，语言设置要同时送到两处。

还需要：`settings.json` 加 `lang` 字段、编辑态卡片加语言选择、决定首次运行时
是跟随系统语言还是默认中文。

> **建议排在面板布局之后做。** 两者耦合——布局定了才知道每格能给多宽，
> 先做多语言等于布局一改就得重做一遍。

## 功能

### 触发键可配

现在写死 Alt（`GetAsyncKeyState(VK_MENU)`）与 `Ctrl+Alt+F10`（编辑态）。
当初明确说"这一版先不做"。

### 常显模式

设计里留过这条兜底——万一 `GetAsyncKeyState` 在某些环境不工作，
至少还能常显。目前只有开发页的 `v` 键，正式版没有这个开关。

### 价格表未加载时的提示

设计里写过"首次运行且无网则净资产项显示『价格表未加载』"，实际没做——
现在会静默退到内嵌快照。快照会随版本变旧，用户看到的是**看起来正常但偏低**的数字，
比明说更糟。

### 敌方英雄失踪计时

数据可行（`minimap_enemyicon` 带英雄名 + 坐标），但实测每个敌人每局消失 11~19 次、
中位仅 5~19 秒，直接做成提醒会非常吵。

**卡在设计而不是实现上**：得先想清楚"多久才算失踪"，以及怎么表达才不打扰。
